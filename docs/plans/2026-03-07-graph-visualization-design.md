# Graph Visualization Design

## Problem
BNF formulas are generated by VLLM and stored as raw text in SpacetimeDB `program.raw_base`. There's no way to visually verify the graph structure. Need a visual graph panel to inspect parsed BNF output.

## Architecture

### Data Flow
```
Program.raw_base (BNF text)
  → TypeScript BNF parser → { nodes[], edges[] }
  → Cytoscape.js → interactive force-directed graph
```

### Components
1. **`src/api/bnfParser.ts`** — Parse raw BNF text into graph nodes/edges
   - Extract `{KIND:CODE@REGION}` node patterns
   - Extract edge operators: `→`, `⊣`, `⇌`, `⊃`, `⊂`, `~>`, `|>`
   - Extract rank sections: `@R0`, `@R1`, `@R2`, `@R3`
   - Return `{ nodes: ParsedNode[], edges: ParsedEdge[] }`

2. **`src/components/GraphPanel.tsx`** — Replace current table-only panel
   - Cytoscape.js canvas for force-directed graph
   - Load BNF from selected program's `raw_base`
   - Parse button to trigger parsing
   - Node details on click (kind, code, region, state)
   - Edge details on hover (type, coefficient)
   - Layout toggle: force-directed / hierarchical / circle
   - Filter by rank (R0/R1/R2/R3)

### Node Styling (by kind prefix)
- `L.nt` neurotransmitter → #6c8cff (blue)
- `L.h` hormone → #ff8c42 (orange)
- `L.p` peptide → #4caf50 (green)
- `R:` receptor → #ab47bc (purple)
- `K:` kinase/enzyme → #f44336 (red)
- `Gp:` G-protein → #ffca28 (yellow)
- `2m:` second messenger → #26c6da (cyan)
- Other → #888 (grey)

### Edge Styling (by operator)
- `→` causal: solid arrow
- `⊣` inhibition: red T-bar
- `⇌` bidirectional: double arrow
- `⊃`/`⊂` containment: dashed
- `|>` pipe: dotted

### Library: Cytoscape.js
- Mature, lightweight (~300KB), handles 100s of nodes
- Force-directed (cose) + hierarchical (dagre) layouts
- Rich CSS-like styling API
- Click/hover events for node/edge inspection

### Dependencies
- `cytoscape` — core library
- `cytoscape-dagre` — hierarchical layout (optional)
