BioChain Pipeline Overview
==========================

4-layer biochemical signal cascade notation system.
Converts natural language clinical descriptions into structured BNF formulas.

PIPELINE ORDER
--------------
BASE -> PLASTICITY -> META -> CONVERGENCE

Each layer depends on all prior layers. Convergence closes the diamond.

LAYERS
------
BASE          Single-snapshot signal cascade analysis.
              chains->integration->protocol->conditional->EMIT.
              Operators: @domain, chain, integrate, protocol, conditional, composite, dysreg, observable.
              Symbols: {} [] @ -> => ~> |> integrate protocol conditional composite dysreg observable
              Fates: loop+ loop- loop0 clearance sequester diffuse metabolize

PLASTICITY    Change map between BASE snapshots. Delta0->Delta3 upward cascade.
              Operators: delta, cascade.
              Symbols: delta bind tau cascade

META          Developmental/epigenetic program layer. Top-down.
              Operators: architecture, program, remodel, setpoint.
              Symbols: arch program remodel setpoint (tilde variants)

CONVERGENCE   Diamond closure. Computes convergence state from all 3 layers.
              Operators: contour, trajectory, risk, flag, monitor.
              Symbols: contour trajectory risk flag monitor
