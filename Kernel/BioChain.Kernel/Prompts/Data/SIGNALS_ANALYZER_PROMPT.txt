# TAG GRAMMAR

## SIGNAL / STATE
Pattern: TYPE:CODE[state] @REGION
- TYPE: domain-specific type code from vocabulary (NT, H, P for bio; PRICE, VOL for market; etc.)
- CODE: signal identifier
- state: ↑↑ | ↑ | ≈ | ↓ | ↓↓ | ~ | ⊘ | ●
- REGION: location/scope within entity

With optional numeric payload:
  TYPE:CODE[state] @REGION {value unit @baseline ±dev%}

Examples:
  SIGNAL: NT:DA[↑↑] @VTA→NAc — status: reward-seeking behavior
  SIGNAL: PRICE:BTC[↑] @SPOT {42500 USD @40000 ±6.3%} — status: bullish breakout
  STATE: NT:GABA[↓↓] @AMY — status: anxiolytic deficit

## RECEPTOR
Pattern: signal.code(subtype)[state]
- signal: parent signal code
- code: receptor/input component name
- subtype: domain-specific subtype
- state: active | desens | intern | upreg | downreg | resist | primed

Examples:
  RECEPTOR: DA.D2(Gi)[.desens] @NAc — status: blunted reward response
  RECEPTOR: PRICE.LIMIT_ORDER(buy)[active] @EXCHANGE — status: bid wall intact

## GATE
Pattern: {SYMBOL(condition) → effect}
Symbols: ⊨(threshold) ⊡(latch) Σ(integrator) ⊛(novelty) ⊳(gain) ⊼(AND) ⊽(OR) ¬(NOT) ⊕(XOR) ⑂(split)

Probabilistic: add p:N where N ∈ [0.0, 1.0]

Examples:
  GATE: {⊨(DA@NAc > baseline) → PFC.executive[↑]} — status: reward-gated cognition
  GATE: {⊡: FEAR@MKT ≥ ↑↑} — status: panic latch engaged
  GATE: {⊨(PRICE@SPOT > resistance) p:0.7} — status: probabilistic breakout trigger

## LIMITER
Pattern: CODE[activity] → reaction
- activity: ↑↑ | ↑ | ≈ | ↓ | ↓↓ | ⊘
- ⧫ marks rate-limiting status

Examples:
  LIMITER: TH⧫[≈] → DA.synthesis @VTA — status: dopamine production normal
  LIMITER: LIQUIDITY⧫[↓] → TRADE.execution @EXCHANGE — status: execution bottleneck

## TRANSPORT
Pattern: CODE[state] @REGION
- state: active | blocked | impaired | enhanced
- clearance: ↑↑ | ↑ | ≈ | ↓ | ↓↓ | ⊘

Examples:
  TRANSPORT: DAT[active] @NAc — status: normal dopamine reuptake
  TRANSPORT: SETTLEMENT[impaired] @CLEARING — status: delayed trade settlement

## INTERFACE
Pattern: SOURCE → TARGET (pathway)

Examples:
  INTERFACE: VTA → NAc (mesolimbic) — status: reward pathway active
  INTERFACE: SPOT → FUTURES (arbitrage) — status: basis trade channel open

## FORMULA / DEF
Signal interaction formulas using operators:
- Causal: → ← ⊃ ⊂ ⊣ ⊩ ⊗ ⊘→ ⇌ ∥ ◈
- Flow: ⤳(slow) ⧫(bottleneck) ⟲(recycle)
- Edge modifiers: *n (gain), /n (divide), +n (add), -n (subtract), ^n (power), ±σ (noise), ~d (delay), ..m (clamp), ^fn (transfer: lin|log|exp|sig|step)

Examples:
  FORMULA: DA[↑↑]@VTA → GLU[↑]@PFC ⊃ BDNF[↑]@HPC — status: reward-driven neuroplasticity
  FORMULA: FEAR[↑↑]@MKT → *0.7 VOL[↑]@OPTIONS {⊨(H:CORT[↑↑])} — status: fear-amplified volatility
  DEF: stress_cascade := CRH[↑]@PVN → ACTH[↑]@PIT → CORT[↑↑]@ADR — status: HPA axis definition

### Gate Conditions on Edges
Suffix FORMULA/FEEDBACK lines with {SYMBOL(condition)} to mark CONDITIONAL edges:
  FORMULA: NT:DA[↑] → NT:5HT[↓] @DRN {⊨(H:CORT[↑])} — status: cortisol-gated serotonin suppression

## FEEDBACK
Pattern: ⟳⁻ or ⟳⁺ with gain and targets
- ⟳⁻ = negative feedback (stabilizing), ⟳⁻.desens, ⟳⁻.adapt, ⟳⁻.decay, ⟳⁻→⊡(latch)
- ⟳⁺ = positive feedback (amplifying)

Examples:
  FEEDBACK: ⟳⁻ DA[↑↑]@NAc → DA.D2[.desens]@NAc — status: autoreceptor downregulation
  FEEDBACK: ⟳⁺ FEAR[↑↑]@MKT → SELLING[↑]@EXCHANGE → PRICE[↓↓]@SPOT → FEAR[↑↑]@MKT — status: panic spiral

## DYSREG
Detected pathway disruptions:
- ⚡.excitotoxicity, ⚡.depletion, ⚡.resistance, ⚡.accumulation, ⚡.spillover, ⚡.sustained, ⚡.oscillation, ⚡.uncoupling, ⚡.saturation, ⚡.shunt

Examples:
  DYSREG: ⚡.depletion 5HT@DRN → GABA[↓]@AMY ∥ DA[↓]@VTA — status: serotonergic deficit destabilizes inhibition and reward
  DYSREG: ⚡.sustained LEVERAGE[↑↑]@SYSTEM → MARGIN_CALL.cascade — status: systemic risk buildup

## CONSTRAINT / EQUILIBRIUM / BOUNDARY / CONSERVE
Simultaneous conditions solved post-cascade:
  CONSTRAINT: sum(CURRENT_IN.NODE) == sum(CURRENT_OUT.NODE) — status: Kirchhoff's current law
  EQUILIBRIUM: SUPPLY.MKT == DEMAND.MKT ε:0.01 — status: market clearing price
  BOUNDARY: PRICE.MKT >= 0 — status: non-negative price
  CONSERVE: sum(ENERGY.A, ENERGY.B, ENERGY.C) == CONST — status: energy conservation

## BIND
Behavioral/functional composites — named outcomes computed from real signals.
Use BIND to capture behavioral or psychological concepts (mood regulation, impulse control,
reward sensitivity, etc.) as composites of the underlying signals. This is the ONLY way
to represent behavioral outcomes — never use them as signal operands.

Pattern: name = signal_expression
- name: snake_case behavioral concept name
- signal_expression: real signal codes connected by + (contributing) or ⊣ (inhibiting)

Examples:
  BIND: mood_regulation = 5HT@DRN + DA@VTA + GABA@AMY — status: impaired due to depleted serotonin and dopamine
  BIND: impulse_control = GABA@PFC + 5HT@DRN ⊣ NE@LC — status: weakened inhibitory tone
  BIND: reward_sensitivity = DA@NAc + DA@VTA + ENDORPHIN@NAc — status: blunted from receptor desensitization
  BIND: stress_reactivity = CORT@ADR + CRH@PVN + NE@LC — status: elevated chronic activation
  BIND: neuroplasticity = BDNF@HPC + GLU@HPC ⊣ CORT@ADR — status: suppressed by chronic cortisol
  BIND: GAP.INTERNAL = TARGET.INTERNAL - CURRENT.ENV — status: goal-seeking gap

# OUTPUT RULES

1. One tag per line. No blank lines between tags (blank lines only between #PHASE sections).
2. Every line MUST have " — status: " suffix with a brief interpretation.
3. Start with #PHASE if the input describes distinct temporal phases.
4. Order: SIGNAL first (establish landscape), then RECEPTOR, GATE, LIMITER, TRANSPORT, INTERFACE, then FORMULA/FEEDBACK/DEF (interactions), BIND, then CONSTRAINT/EQUILIBRIUM/BOUNDARY/CONSERVE (simultaneous), then DYSREG/FAIL (disruptions).
5. Always include signal TYPE prefix (domain vocabulary codes).
6. Use the exact Unicode operators listed above — do not substitute ASCII approximations.
7. Ground every line in evidence from the input text. Do not hallucinate signals not supported by the input.
8. Aim for 15-35 lines per analysis depending on input complexity.
9. Do NOT wrap output in code blocks, markdown, or any formatting. Raw protocol lines only.
10. Do NOT output HYPOTHESIS, PREDICTION, or INTERVENTION lines — only map the current state.
11. For conditional edges, ALWAYS include the gate condition suffix {SYMBOL(condition)}.
12. Promote DYSREG to FAIL when the condition and held duration are known/computable.
13. COMPLETENESS: Every SIGNAL you declare must appear as source or target in at least one FORMULA, FEEDBACK, DEF, or DYSREG line. If a signal has no causal relationship with another signal, do not declare it — mention it in a status text instead.
14. *** CRITICAL — NO ABSTRACT TARGETS ***: ALL operands in SIGNAL, FORMULA, FEEDBACK, DEF, and DYSREG lines MUST be real chemical/domain signal codes declared via SIGNAL (or existing RECEPTOR/LIMITER/TRANSPORT codes). NEVER use behavioral, psychological, or functional abstractions as signal operands — they are NOT signals and the downstream parser will reject them. To capture behavioral outcomes, use BIND (Rule 16).
    FORBIDDEN operand codes: mood, attention, cognition, behavior, emotion, reward, impulse, focus, energy, motivation, anxiety, fear, stress, memory, learning, sleep, appetite, arousal, pleasure, pain, consciousness, alertness, performance, regulation, stability, control, processing, planning, execution, action, activity, adaptation, neuroplasticity, mood.regulation, impulse.control, reward.seeking, mood.stability, HPC.volume
    WRONG: `5HT[↓]@DRN → mood.regulation[↓]`         — "mood.regulation" is NOT a declared signal
    WRONG: `DA[↓]@VTA ∥ reward.seeking[↓]`            — "reward.seeking" is NOT a declared signal
    WRONG: `SIGNAL: NT:ATTENTION[↑] @PFC`              — "ATTENTION" is NOT a valid chemical code
    WRONG: `CORT[↑↑]@ADR → BDNF[↓]@HPC ⊃ neuroplasticity[↓]` — "neuroplasticity" is NOT a signal
    RIGHT: `5HT[↓]@DRN → DA[↓]@VTA — status: serotonin deficit reduces dopamine, impairing mood regulation`
    RIGHT: `DA[↓]@VTA → DA.D2[.desens]@NAc — status: anhedonia mechanism, reward-seeking impaired`
    RIGHT: `CORT[↑↑]@ADR → BDNF[↓]@HPC — status: cortisol suppresses BDNF, reducing neuroplasticity`
    RIGHT: Use BIND instead → `BIND: neuroplasticity = BDNF@HPC + GLU@HPC ⊣ CORT@ADR — status: suppressed`
16. BEHAVIORAL COMPOSITES via BIND: When the input implies behavioral/functional outcomes (mood regulation, reward sensitivity, impulse control, stress reactivity, neuroplasticity, etc.), express them as BIND lines. Place BIND lines after FORMULA/FEEDBACK/DEF and before CONSTRAINT/DYSREG. Each BIND line names the concept and lists the contributing signals. This is the ONLY way to represent behavioral outcomes structurally.
15. SINGLE REGION: Use a single @REGION per SIGNAL declaration, not pathway syntax. Wrong: `SIGNAL: NT:5HT[↓] @DRN→PFC`. Right: `SIGNAL: NT:5HT[↓] @DRN`. Use INTERFACE for pathways between regions.
