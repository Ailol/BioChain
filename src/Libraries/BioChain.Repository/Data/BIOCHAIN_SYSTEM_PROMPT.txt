Parser Mapping: LLM Output → DB Rows
======================================
Every line → protocol row (tag, formula, status, phase) + component FKs

  TAG            → DB Action
  ──────────────────────────────────────────────────────────
  SIGNAL:        → UPSERT signal row. Create protocol row. Link signal FKs.
  RECEPTOR:      → UPSERT receptor row. Create protocol row. Link receptor_id.
  GATE:          → UPSERT gate row. Create protocol row. Link gate_id.
  LIMITER:       → UPSERT limiter row. Create protocol row. Link limiter_id.
  TRANSPORT:     → UPSERT transporter row. Create protocol row. Link transporter_id.
  INTERFACE:     → UPSERT interface row. Create protocol row. Link interface_id.
  FEEDBACK:      → Create protocol row. Link signal/receptor FKs.
  FORMULA:       → Create protocol row. Link signal_source_id + signal_target_id.
  STATE:         → UPSERT signal or receptor row. Register snapshot.
  DEF:           → Create protocol row (definition, uses := and ∥).
  DYSREG:        → Create protocol row + data row kind='inferred'.
  HYPOTHESIS:    → Create data row kind='hypothesis'. content: {confidence}.
  PREDICTION:    → Create data row kind='prediction'. content: {timeframe}.
  INTERVENTION:  → Create data row kind='clinical'. content: {target, action}.
  #PHASE:        → Set protocol.phase for subsequent lines.

Protocol Columns (new)
=======================
  protocol.tag:     VARCHAR(15) — line tag from LLM output
  protocol.status:  VARCHAR(50) — "— status:" suffix value
  protocol.phase:   VARCHAR(50) — current #PHASE name

Operators (stored in protocol.formula TEXT)
============================================
  Causal:    → ← ⊃ ⊂ ⊣ ⊩ ⊗ ⊘→ ⇌ ∥ ◈
  Flow:      ⤳(slow) ⧫(bottleneck) ⟲(recycle)
  Feedback:  ⟳⁻(neg) ⟳⁺(pos) ⟳⁻.desens ⟳⁻.adapt ⟳⁻.decay ⟳⁻→⊡(latch)
  Gates:     ⊨(threshold) ⊡(latch) Σ(integrator) ⊛(novelty) ⊳(gain)
             ⊼(AND) ⊽(OR) ¬(NOT) ⊕(XOR) ⑂(split)
  Dysreg:    ⚡.excitotoxicity ⚡.depletion ⚡.resistance ⚡.accumulation
             ⚡.spillover ⚡.sustained ⚡.oscillation ⚡.uncoupling ⚡.saturation ⚡.shunt

                        simulation | cascade_step | hypothesis | prediction | loop_check | checkpoint
